  SECTION 1 — HOURLY OPERATIONAL CHECKLIST
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Run this at every confirmed 1H bar close (top of each hour, UTC).
Total time if no signal: under 2 minutes.

  STEP  ACTION                                             IF TRUE → NEXT
  ──────────────────────────────────────────────────────────────────────────
  1     Confirm previous bar is CLOSED on Bybit            —
        (next bar has opened; don't act on forming bar)

  2     Pull latest 1H OHLCV for all 4 assets              —
        AVAXUSDT, ADAUSDT, SOLUSDT, XRPUSDT

  3     Run signal generator                                —
        → get P(BUY) per asset

  4     For each asset, evaluate:                           Signal candidate
        LONG  if P(BUY)  >= 0.55
        SHORT if P(BUY)  <= 0.45
        FLAT  → skip this asset, move to Step 5

  5     For each signal candidate:
        a. ATR_ratio = current_ATR / ATR_median(72)
           If ATR_ratio < 0.75 → SKIP (low vol), log: blocked_low_vol
        b. Is there already an open position on this asset?
           If YES → SKIP, log: blocked_existing_position
        c. If passed (a) and (b) → begin 15m monitoring (Section 2)

  6     For each OPEN position:
        a. Read bar HIGH and LOW just closed
        b. LONG:  if bar_low  <= stop_price → EXIT at stop  (Priority 1)
                  if bar_high >= tp_price   → EXIT at tp    (Priority 2)
        c. SHORT: if bar_high >= stop_price → EXIT at stop  (Priority 1)
                  if bar_low  <= tp_price   → EXIT at tp    (Priority 2)
        d. Count bars held since entry:
           if bars_held >= 24 → TIME EXIT at this bar's close (Priority 3)
        e. If exit triggered:
           - Record exit_time, exit_price, exit_reason
           - Compute net_pnl, r_multiple, mfe_r, mae_r
           - Fill trade log row completely

  7     Update MFE/MAE for all open positions:
        LONG : mfe_price = max(mfe_price, bar_high)
               mae_price = min(mae_price, bar_low)
        SHORT: mfe_price = min(mfe_price, bar_low)   [most favorable low]
               mae_price = max(mae_price, bar_high)  [most adverse high]

  8     Log timestamp + "no signal" if nothing happened   —
        (maintain a continuous hourly audit trail)

  SECTION 2 — 15m MONITORING WINDOW (when signal detected at time T)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Record at signal detection: symbol, direction, signal_time, atr_1h, reference_price = 1H close.

────────────────────────────────────────────────────────────────────
  APPROACH A  (T+0m to T+60m  |  15m bars 1, 2, 3, 4)
────────────────────────────────────────────────────────────────────

  At each 15m bar close, record:
    bar_close > bar_open  (for LONG) → aligned
    bar_close < bar_open  (for SHORT) → aligned

  At T+60m (bar 4 closes):
    aligned_count < 2 → CANCEL
      log: a_filter_result = fail, a_aligned_bars = N
      Stop monitoring. No trade.

    aligned_count >= 2 → A PASSED
      log: a_filter_result = pass, a_aligned_bars = N
      Begin Approach B immediately.

  MISSED DATA RULE:
    If 15m feed is unavailable for any bar in window 1–4:
    → CANCEL trade. Log: a_filter_result = no_data.
    Do not fall back to 1H entry.

────────────────────────────────────────────────────────────────────
  APPROACH B  (T+60m to T+120m  |  15m bars 5, 6, 7, 8)
────────────────────────────────────────────────────────────────────

  State: WAITING_PULLBACK (initial)

  At each 15m bar close:

    If state = WAITING_PULLBACK:
      LONG:  bar_close < reference_price  → state = WAITING_RESUMPTION
      SHORT: bar_close > reference_price  → state = WAITING_RESUMPTION

    If state = WAITING_RESUMPTION:
      LONG:  bar_close > bar_open  → ENTER here
      SHORT: bar_close < bar_open  → ENTER here

  FALLBACK (bar 8 closes, no pattern completed):
    → ENTER at close of bar 8
    → Use reference_price as pre-slippage entry price
    → Log: b_pullback_found = FALSE

  ENTRY FILL (after pattern or fallback):
    pre_slip = pullback_bar_close  (or reference_price if fallback)
    LONG  fill = pre_slip * 1.0002
    SHORT fill = pre_slip * 0.9998
    → log: entry_time, entry_price_fill, b_pullback_found

────────────────────────────────────────────────────────────────────
  CALCULATE AND RECORD AT ENTRY
────────────────────────────────────────────────────────────────────

  LONG:
    stop_price  = entry_price_fill - 1.5 * atr_1h
    tp_price    = entry_price_fill + 2.5 * atr_1h
    risk_1r_usd = (entry_price_fill - stop_price) * units
    max_bar     = entry_bar_index + 24

  SHORT:
    stop_price  = entry_price_fill + 1.5 * atr_1h
    tp_price    = entry_price_fill - 2.5 * atr_1h
    risk_1r_usd = (stop_price - entry_price_fill) * units
    max_bar     = entry_bar_index + 24

  units = (equity * 0.10) / entry_price_fill

  Set Bybit paper SL and TP alerts immediately.
  Record stop_price and tp_price in trade log.

  SECTION 3 — TRADE LOG TEMPLATE  (paper_trades_tier1.csv)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

One row per CLOSED trade. Populate at trade close.

  Column              Type    Fill when       Allowed values / notes
  ────────────────────────────────────────────────────────────────────────
  trade_id            INT     signal          sequential 1, 2, 3, ...
  symbol              STR     signal          AVAXUSDT | ADAUSDT | SOLUSDT | XRPUSDT
  signal_time         DT/UTC  signal          e.g. 2026-03-19 14:00:00
  direction           STR     signal          long | short
  a_filter_result     STR     T+60m           pass | fail | no_data
  a_aligned_bars      INT     T+60m           0 | 1 | 2 | 3 | 4  (blank if no_data)
  b_pullback_found    BOOL    entry           TRUE | FALSE | N/A (if A failed)
  entry_time          DT/UTC  entry           blank if A failed
  entry_price_fill    FLOAT   entry           post-slippage fill; blank if A failed
  atr_1h              FLOAT   signal          14-bar 1H ATR at signal bar close
  stop_price          FLOAT   entry           calculated from entry_fill + ATR
  tp_price            FLOAT   entry           calculated from entry_fill + ATR
  exit_time           DT/UTC  exit            blank until closed
  exit_price          FLOAT   exit            actual fill (SL/TP/time rule)
  exit_reason         STR     exit            stop | tp | time
  net_pnl_usd         FLOAT   exit            gross_pnl - commission
  r_multiple          FLOAT   exit            net_pnl_usd / risk_1r_usd
  mfe_r               FLOAT   exit            (peak_favorable - entry) / risk_1r for long
  mae_r               FLOAT   exit            (entry - trough) / risk_1r for long
  notes               STR     anytime         gap_stop | data_outage | missed_check | blank

  r_multiple formula:
    LONG:  r_multiple = (exit_price - entry_price_fill) / (entry_price_fill - stop_price)
    SHORT: r_multiple = (entry_price_fill - exit_price) / (stop_price - entry_price_fill)
    Deduct commission before computing: net_pnl = gross_pnl - (entry+exit)*units*0.001

  mfe_r (long):  (max_bar_high_during_trade - entry_price_fill) / (entry_price_fill - stop_price)
  mae_r (long):  (entry_price_fill - min_bar_low_during_trade)  / (entry_price_fill - stop_price)
  For short:     flip the numerator direction accordingly.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

5.1  TOP OF EVERY HOUR  (2–4 min if no signal, up to 2h if signal active)

  00:xx UTC — execute Section 1 checklist completely
  Record in hourly log: timestamp | signals_checked | any_signal | open_positions

5.2  WHEN A SIGNAL IS DETECTED  (switch to 15m mode)

  Immediately upon detecting a signal at 1H close:

    1. Open Bybit chart for the signaled asset on 15m timeframe
    2. Note signal_time, direction, reference_price (1H close), atr_1h
    3. Start A-window timer: 4 × 15m = 60 min

  At T+15m, T+30m, T+45m: record each 15m bar close vs open
  At T+60m:
    aligned_count >= 2 → proceed to B, stay on chart
    aligned_count < 2  → log A_fail, close chart, return to normal

  During B window (T+60m to T+120m):
    Monitor each 15m bar close.
    When pullback+resumption or fallback triggers:
    → Record entry immediately (entry_time, entry_price_fill)
    → Calculate and record stop_price, tp_price
    → Place SL and TP orders on Bybit paper account
    → Log entry row in trade log (leave exit columns blank)

5.3  WHILE A POSITION IS OPEN

  At every 1H close (Section 1, Step 6):
    Check SL/TP breach.
    Check bar count (bars_held = current_bar_index - entry_bar_index).
    Update mfe_price and mae_price.

  Between hourly checks:
    Rely on Bybit paper account SL/TP alerts as backup.
    If SL/TP hits between hourly checks:
    → Record actual fill from Bybit
    → Note "between_hourly_checks" in notes field

5.4  END OF DAY  (fixed UTC time — use 00:00 UTC daily)

  Duration: 15–20 minutes.

  STEP  ACTION
  ──────────────────────────────────────────────────────────────────────
  1     Reconcile trade log with Bybit paper account order history.
        Every fill in Bybit should have a matching row in trade log.
        Every trade log row should have a matching Bybit fill.
        Flag any discrepancy.

  2     Complete any trade rows that closed today:
        exit_time, exit_price, exit_reason, net_pnl_usd, r_multiple,
        mfe_r, mae_r.

  3     Update running daily summary row:

        Date | Closed trades | Open positions | Combined PF (cumulative)
             | Avg R today   | A-pass rate today | Equity

  4     Check alarm thresholds (Section 4.4):
        If any metric outside expected range:
        → Note it. Do not adjust parameters.
        → If alarm persists 3+ days: escalate to weekly review.

  5     Record open positions status:
        symbol | entry_time | bars_held | current_mae_r
